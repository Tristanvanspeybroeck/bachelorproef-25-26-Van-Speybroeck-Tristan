\chapter{\IfLanguageName{dutch}{Inleiding}{Introduction}}%
\label{ch:inleiding}

Artistic gymnastics is a technically demanding sport in which coordination, strength, mobility and timing must be well aligned. Even simple movements require correct execution in order to be performed efficiently and safely. In recreational contexts, gymnasts are regularly confronted with complex elements for which they have not yet developed sufficient body control or strength. As a result, technical execution errors often occur.

The kip on bars is an important transition element within women's gymnastics. The element requires a combination of swing momentum, hip closure, arm extension and active shoulder action to move from a hanging position into support on the bar. Especially for recreational gymnasts, this movement appears to be technically challenging. This regularly leads to errors such as bent arms, insufficient hip closure or weak shoulder push.

Correct technical execution is not only important for performance improvement, but also for injury prevention. Repeatedly performing incorrect movement patterns can contribute to overuse injuries, especially in the shoulder and wrist during movements on the bar. Early detection and correction of technical errors is therefore important within a safe training environment.

Within recreational gymnastics clubs, technical elements are usually taught in groups. Coaches supervise several athletes at the same time, which means there is limited time for a thorough individual analysis of each execution. Feedback is mainly based on visual observation and the coach's experience. Advanced 3D motion analysis systems exist, but they require specialised equipment and are usually not financially feasible for recreational clubs. There is therefore a clear gap between laboratory-based motion analysis and the practical reality in the training hall.

Recent developments in markerless pose estimation make it possible to determine joint positions based on standard video footage, without using sensors or markers. In addition, Large Language Models (LLMs) can convert information into understandable textual feedback. The combination of these technologies offers possibilities for developing an accessible AI-based support system for technical analysis in recreational gymnastics.

This bachelor thesis investigates to what extent such a system is feasible and usable for generating technical feedback on the kip on bars.

\section{\IfLanguageName{dutch}{Probleemstelling}{Problem Statement}}%
\label{sec:probleemstelling}

Within recreational and low-competitive gymnastics clubs, technical elements such as the kip on bars are taught to gymnasts aged approximately 10 years and older. In this context, clubs generally do not have access to specialised motion analysis equipment and coaches rely on visual observation.

The target group of this research consists of:

\begin{itemize}
    \item Recreational and low-competitive gymnasts
    \item Coaches within recreational gymnastics clubs
    \item Gymnastics clubs without access to specialised motion analysis
\end{itemize}

For this target group, an accessible video-based analysis system can offer added value by:

\begin{itemize}
    \item Consistently detecting predefined technical errors
    \item Supporting coaches in formulating targeted feedback
    \item Increasing athletes' awareness of execution quality
\end{itemize}

The central challenge is to investigate whether an AI-based solution using standard video footage can provide feasible and usable support within this recreational training context.

\section{\IfLanguageName{dutch}{Onderzoeksvraag}{Research question}}%
\label{sec:onderzoeksvraag}

The central research question is as follows:

\textit{To what extent can an AI-based system using markerless video analysis generate technically useful feedback for recreational gymnasts performing the kip on bars?}

To answer this research question, the following sub-questions are investigated. These relate partly to the problem domain and partly to the solution domain.
\newline
\textbf{Problem domain}:

\begin{enumerate}
    \item Which technical errors occur most frequently during the kip?
    \item Why are recurring technical errors sometimes not noticed by coaches, and how can this be systematically recorded?
    \item Which characteristics make technical feedback effective and useful for recreational gymnasts?
\end{enumerate}

\textbf{Solution domain}:

\begin{enumerate}
    \item Which markerless pose estimation method is most suitable for analysing the kip on bars within a recreational training context?
    \item To what extent can technical errors be detected automatically based on pose data?
    \item To what extent can a Large Language Model provide technically correct and useful feedback based on detected errors?
    \item What are the limitations of an AI-based feedback system within this application?
\end{enumerate}

\section{\IfLanguageName{dutch}{Onderzoeksdoelstelling}{Research objective}}%
\label{sec:onderzoeksdoelstelling}

The aim of this bachelor thesis is to develop and evaluate a proof-of-concept of an AI-based system that:

\begin{enumerate}
    \item Extracts joint positions from 2D video footage using markerless pose estimation.
    \item Detects four frequently occurring technical errors in the kip on bars using a rule-based approach:
    \begin{itemize}
        \item Bent arms during the pull phase
        \item Insufficient hip closure
        \item Early hip opening
        \item Weak shoulder push in the support phase
    \end{itemize}
    \item Converts detected errors into structured parameters.
    \item Generates understandable and targeted technical feedback through a Large Language Model based on these parameters.
\end{enumerate}

In addition, this research exploratively investigates to what extent the selected error types can be detected using 2D pose estimation and whether the generated feedback is substantively aligned with the detected errors.

The research focuses on technical feasibility and practical usability within a recreational context, and not on the development of a fully validated diagnostic system.
