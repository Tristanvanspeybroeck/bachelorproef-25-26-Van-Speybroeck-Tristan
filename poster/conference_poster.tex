    \begin{abstract}        
        This bachelor's thesis investigates to what extent automatic technical feedback on the gymnastics skill kip on the uneven bars is possible through markerless video analysis and Large Language Models. In recreational gymnastics, coaches often supervise several gymnasts at the same time, which means that technical errors are not always noticed systematically. 
        
        For this purpose, a proof-of-concept was developed that converts standard video footage into pose data using MediaPipe Pose Landmarker. Based on this data, joint angles are calculated, movement phases are identified, and four predefined error types are analyzed using a rule-based approach. The detected errors are then structured in JSON format and used as input for feedback generation through a local LLM. 
        
        The results show that this approach is technically feasible within a limited test set. The pipeline was able to recognize differences between one good execution and two incorrect executions. At the same time, the quality remains dependent on recording quality, detection noise, selected threshold values, and strict control of the LLM output. Therefore, the system should mainly be considered an exploratory support tool for coaches, not a replacement for human expertise.
    \end{abstract}

        \section{Introduction}
        
        Artistic gymnastics is a technically demanding sport in which timing, strength and body control are important. In the kip on the uneven bars, gymnasts move from a hanging position to a front support on the bar. This movement requires swing momentum, hip closure, arm extension and active shoulder push.
        
        In recreational gymnastics, coaches often supervise several gymnasts at the same time. As a result, there is limited time to analyze each execution individually and systematically. Technical errors such as bent arms, insufficient hip closure, early hip opening or insufficient shoulder push are therefore not always noticed consistently.
        
        Advanced movement analysis exists, but is usually not practical or financially feasible for recreational clubs. Markerless video analysis and Large Language Models therefore offer a possible low-threshold support tool for technical analysis and feedback.
        
        \textbf{Research question:} To what extent can an AI-based system, using markerless video analysis, generate technically useful feedback for recreational gymnasts performing the kip on the uneven bars?

        \section{Experiments}
        
        For the proof-of-concept, an analysis pipeline was developed that converts standard video footage of the kip on the uneven bars into technical feedback.
        
        \begin{itemize} 
            \item \textbf{Pose estimation:} MediaPipe Pose Landmarker detects the gymnast's body landmarks in each frame.
            \item \textbf{Parameter extraction:} based on these landmarks, the hip angle, shoulder angle, trunk angle and elbow angle are calculated.
            \item \textbf{Phase segmentation:} the movement is divided using rules into the swing phase, pull phase, hip closure phase and support phase.
            \item \textbf{Error detection:} four predefined errors are analyzed: bent arms, insufficient hip closure, early hip opening and insufficient shoulder push.
            \item \textbf{Feedback generation:} the detected errors are stored in JSON format and converted into Dutch textual feedback using a local LLM.
        \end{itemize}
        
        The LLM does not detect errors itself. The technical assessment is performed by the rule-based Python script. The LLM is only used to clearly phrase the errors that were actually detected.

        \section{Conclusions} 
        
        The proof-of-concept shows that automatic technical feedback on the kip on the uneven bars is feasible to a limited extent. Standard video footage could be converted into pose data, after which relevant joint angles were calculated and predefined errors were analyzed using a rule-based approach. The results show that the pipeline was able to recognize differences between one good execution and two incorrect executions. In the good execution, no errors were detected, while in the incorrect attempts mainly bent arms and insufficient shoulder push were identified. The LLM proved useful as a language component, but not as an autonomous evaluator. Therefore, the LLM was only used to convert actually detected errors into understandable feedback. The system can therefore support coaches, but does not replace human expertise.
        
       \section{Future research} 
       
       In the future, the proof-of-concept can be further developed by testing it on a larger and more diverse dataset with multiple gymnasts, camera angles and incorrect executions. This would allow the selected threshold values and error rules to be evaluated and refined more thoroughly. In addition, the analysis can be extended with automatic detection of the analysis window, explicit via-points and possibly angular velocities or time normalization. This would allow the pipeline to better handle differences in timing and execution. Feedback generation can also be investigated further. A more powerful or domain-specific language model may produce more natural feedback, as long as the error detection remains controlled. Finally, a simple interface could be developed that allows coaches to upload videos, view results and review feedback.
